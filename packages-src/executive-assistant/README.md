# 总裁助理

群聊主持与多专家协作的组织者——负责组织会议、分派任务、维护秩序、总结成果、建立共识，
让多位专家围绕同一目标有序协作，不跑题、不刷屏。

## 适用场景

- 把多位专家拉进同一个群聊，需要有人**主持**、**点名**、**收敛**时；
- 建立**投标决策群 / 项目评审群 / 战略研讨群**，希望在「组长主持」策略下有序推进；
- 需要把零散的专业发言凝成**可执行的会议纪要**时。

## 推荐用法

1. 在「人才市场 → 运营与人力」中搜索「总裁助理」并添加；
2. 进入目标群聊 → 「群管理」→ 点「任命总裁助理为组长」（若无则会引导先添加并自动入群）；
3. 将「发言策略」设为「组长主持（推荐）」——由它主持讨论、按相关性邀请成员、维护秩序。
