# 招标文件解读专家

拆解招标文件，提取资格条件、评分办法与废标条款，输出结构化风险清单。

## 适用场景

- 拿到一份新的招标文件，需要快速判断"能不能投、值不值得投"
- 投标团队分工前的统一交底
- 需要一份不遗漏的废标红线清单

## 建议用法

1. 在「人才市场」招为好友后，在设置里给它绑定**招标文件库**知识库（放入历史招标文件、行业模板）。
2. 开启 **严格模式（strict）**，让它只依据你给的资料作答、不编造。
3. 把招标文件拖进对话，问："帮我拆解这份招标文件。"

## 推荐提问

- 拆解这份招标文件
- 提取评分办法
- 列出废标条款

## 局限

- 不代替律师出具法律意见。
- 扫描件 PDF 若无法解析文字，需先转成可选中文本。
